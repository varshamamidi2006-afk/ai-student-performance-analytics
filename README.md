# 🎓 AI-Powered Student Performance Analytics & Prediction System

An AI/ML-based system that analyzes student academic data and predicts final performance using Machine Learning.

## 🎯 Objective
To analyze student performance factors and predict the final score using a Random Forest Regression model.

## 📊 Dataset
- 1000 student records
- Synthetic dataset generated for project demonstration

## 🔍 Features
- Attendance
- Study Hours
- Assignment Score
- Internal Marks
- Previous Semester Score
- Participation
- Backlogs

## 🤖 Machine Learning Model
**Random Forest Regressor**

## 📈 Model Performance
- R² Score: **0.93**
- Mean Absolute Error: **3.17**

## ⭐ Key Insight
Study Hours was the most important feature in the model.

## 🎯 Sample Prediction
Predicted Final Score: **99.59**

Performance Category: **Excellent**

## 🛠️ Technologies Used
- Python
